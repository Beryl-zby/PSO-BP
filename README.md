# 苏北五市需水预测与 WaterLab

当前主模型为**正则BP集成（无PSO）**。基于2010—2023年历史数据，预测2024—2030年五种SSP情景、三条用水效率路径，共15组、105个年度预测值。仓库名称PSO-BP沿用早期项目名称。

## 三条用水效率路径

同一SSP下保持社会经济发展输入一致，改变农业和工业的用水强度路径。

| 路径 | 设置 |
|---|---|
| 近期平均效率维持 | 农业、工业强度保持2021—2023年平均水平，作为效率不再改善的计算对照 |
| 历史趋势延续 | 延续历史估计的农业、工业用水强度变化 |
| 江苏政策参考约束 | 在历史趋势上叠加2030年农业、工业政策参考，达到更严格的强度要求 |

农业采用灌溉水有效利用系数0.69作为参考；工业参考万元工业增加值用水量11立方米（2000年不变价、不含火电），经价格桥转换后使用。播种面积作为灌溉面积代理，生活用水驱动未设置额外政策节水约束。苏北2030年173.258662933亿立方米是折算总量参考，保留在结果表校核，不截断预测，也不在趋势图中绘制。

## 当前BP开发回测结果

当前为 `regularized-bp-v2`，模型与校准方案只在训练前缀内选择。以下数值来自 [07_BP_Ensemble/results/result.json](07_BP_Ensemble/results/result.json)，对应2022年历史总用水量已修正为194.3亿立方米的输入版本。

| 检验 | MAPE（%） | MAE（亿立方米） | RMSE（亿立方米） | MSE（亿立方米的平方） |
|---|---:|---:|---:|---:|
| 固定起点 | 4.571553 | 8.613739 | 14.229281 | 202.472435 |
| 逐年滚动 | 5.958933 | 10.970659 | 15.768784 | 248.654554 |

固定起点以2010—2019年训练，预测2020—2023年；滚动起点每年使用此前历史重新训练。2020—2023年已用于模型探索，这些结果属于开发回测。同一输入下，旧末年锚定BP固定/滚动MAPE为4.344883%/9.065537%；新校准固定指标有所上升、滚动指标下降，详见[模型说明](07_BP_Ensemble/README.md)。旧输入下PSO-BP约0.8%的MAPE不代表当前结果；本页不再用旧排名说明当前模型优劣。

## MATLAB运行

将MATLAB当前目录设为本仓库根目录，执行：

```matlab
T = main_ThreePathForecast(true);
```

该入口读取源工作簿、训练正则BP集成、生成含路径输入的最新Excel与PNG，并同步工作台输入和MATLAB预测缓存。源工作簿只读。模型与主流程使用基础MATLAB；其他对照方法的工具箱要求见各自目录。Node需在PATH中，或用环境变量 `WATERLAB_NODE` 指定。仅重新导出当前模型版本且已匹配输入指纹的BP结果可运行 `main_ThreePathForecast(false)`。

## WaterLab四个模块

| 模块 | 功能 |
|---|---|
| 数据与研究设置 | 统一录入输入工作簿和研究背景 |
| Agent预测 | 依据数据诊断提出候选模型与参数，执行验证并选择方案 |
| BP预测 | 按指定正则BP集成方法计算15组预测 |
| 结果分析与绘图 | 用户选择BP结果、Agent结果或两者对比，共用图表和AI解读 |

LangGraph负责编排；Qwen承担规划、受限执行请求和结果分析。可选AFlow采用受约束的工作流搜索适配。数值预测由程序计算，选优依据验证误差。结果页的AI只能按提问切换允许的图型，方法、记录、SSP和路径由用户选择。

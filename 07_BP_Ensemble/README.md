# 正则BP集成

当前版本为 `regularized-bp-v2`。保持3–1–1网络、12成员、随机小初值、L2正则和原局部求解器，无PSO；修正预测校准对单年波动的传递。

每个训练前缀在末3年进行扩展时间验证，联合选择4个正则参数（0.01、0.03、0.1、1）和3种校准方式：

| 校准 | 预测公式 |
|---|---|
| `last` | 模型输出＋训练末年残差，保留原方案 |
| `none` | 模型直接输出 |
| `median3` | 模型输出＋训练末三年残差中位数 |

校准残差定义为实际值减模型拟合值。每个内验证点的模型、归一化和校准偏移均只使用该点之前的训练行；当前检验目标不参与选择。偏移保存在模型中，回测、未来15组情景和因素响应共用 `water_predict_method`，不会在未来预测时再次强制锚定。

运行 `main_ThreePathForecast(true)` 更新BP结果、Excel、PNG和网页缓存；`false`仅导出当前版本且输入指纹匹配的已训练结果。源工作簿只读，派生表写入结果Excel。Node需在PATH中，或通过环境变量 `WATERLAB_NODE` 指定可执行文件。独立运行模型为 `run_BP_Ensemble`，核验为 `test_BP_Ensemble`。

2022年目标保留为当前输入的194.3。改动前后均使用相同输入和2020—2023开发回测：固定MAPE约4.3449%→4.5716%，滚动MAPE约9.0655%→5.9589%。固定指标有所上升；不能声称所有指标都改善，也不能将此开发结果视为新增独立验证。

当前数据下，固定及四次滚动拟合均选 `none`，全历史模型选 `median3`。2023年滚动预测约174.12，原末年锚定约193.85，实际165。模型仍未解释2022年突增，校准修改不替代输入核查和驱动补充。

情景分解的“基期衔接差”包含模型校准后的2023基值与实际值的差，以及近期平均效率与2023效率的差；两项在JSON中分别保存为 `calibration_base_gap`、`efficiency_only_effect`，不归入发展效应或节水量。

旧 `01_PSO_BP_Ensemble` 和 `06_BP_vs_PSO_BP` 保留原末年锚定对照；它们不采用新校准选参协议。

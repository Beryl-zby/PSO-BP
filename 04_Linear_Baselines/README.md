# 线性模型与持平基准

与三个新方案使用相同输入、时间划分、训练期内选参及实际值锚定。下表为统一回测中实际重新拟合的结果。

| 基准 | 固定MAPE (%) | 滚动MAPE (%) | 固定RMSE | 滚动RMSE |
|---|---:|---:|---:|---:|
| 岭回归（原网格） | 3.347435 | 1.949635 | 5.594441 | 4.228828 |
| 岭回归（加密网格） | 2.242548 | 1.777257 | 3.898005 | 3.778503 |
| 普通线性回归 | 1.438028 | 1.236283 | 2.407261 | 2.694614 |
| 最近实际值 | 7.025775 | 1.980116 | 11.643490 | 5.093291 |

## 代码与运行

`model_Ridge.m`实现岭回归；正则参数为0时为普通最小二乘。`water_linear_suite_model.m`提供共享回测接口和最近实际值基准。

在项目根目录运行`main_ThreeMethodComparison`会计算以上基准；无需另外维护一份不同划分的实验。

结果：[统一JSON](../results/three_methods/comparison.json)、[对比报告](../results/three_methods/三种方法对比报告.md)。验证：[verification.json](../results/three_methods/verification.json)。

原岭回归与原工作簿结果复现一致；当前记录属于2020—2023开发回测。
